Automação de testes

Robot Framework

Para começar a trabalhar com Robot Framework, configure seu ambiente de desenvolvimento com as ferramentas abaixo.

Requisitos

No Windows, instale os seguintes recursos antes de começar a trabalhar com Robot Framework.

Python

Necessário para instalar, executar e gerenciar o Robot Framework e suas bibliotecas.

→

Git Bash

Será utilizado como linha de comando para executar os comandos e projetos.

→

Visual Studio Code

Editor recomendado para desenvolvimento e criação dos testes automatizados.

→

Robot Framework

Framework utilizado para criação, execução e automação dos testes.

→

Ambiente pronto?

Depois de instalar os requisitos, você estará pronto para configurar o Robot Framework e começar a criar seus primeiros testes automatizados.
